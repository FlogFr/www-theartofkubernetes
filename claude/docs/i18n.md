# Internationalisation (English edition)

The site is French-only today, but everything needed for an English version is in place.
Nothing English is published until the steps below are done.

## How it works

- Every content file has a `:lang:`; URLs are prefixed by the language (`/fr/…`,
  `/en/…`). `ARTICLE_LANG_*`/`PAGE_LANG_*` settings keep that scheme for translations.
- A translation is a file with the **same `:slug:`** and a different `:lang:`. Pelican
  links them (`obj.translations`), and `base.html` emits `hreflang` alternates plus
  `x-default` (the French version); the sitemap lists them too.
- UI strings are in `partials/i18n.html` (`strings.fr`, `strings.en` already exist).
- Book data per language: `BOOKS[lang]` in `pelicanconf.py`. Templates fall back to
  `BOOKS[DEFAULT_LANG]` when a language has no entry.
- Home pages per language: `HOME_PAGES`; with two or more entries the header shows a
  language switcher.
- Listing templates filter articles by `lang`, so French and English articles never mix.

## Launching the English edition — checklist

1. **Book data**: add `BOOKS["en"]` (title, format, pages, price, currency, ASIN, store —
   e.g. Amazon.com —, `country` — e.g. `US` —, `url` via `_amazon_url`, `link_rel`,
   cover and OG image derivatives). Ask the author for the real values.
2. **Images**: add the English cover original to `content/images/`, generate derivatives
   with `scripts/make_images.py` (cover 400/800 WebP, OG image 1200×630).
3. **Landing page**: copy `templates/home_fr.html` to `templates/home_en.html` and
   translate the copy and data (`learn`, `audiences`, `chapters`, `faq`,
   `book_description`). English testimonials only if real English readers wrote them.
   Without testimonials the English `Product` has no `review`/`aggregateRating`, and
   `make check` reports it (Search Console "Product snippets"): decide with the author.
4. **Pages**: create `content/pages/en/home.rst` with `:lang: en`, `:slug: home`,
   `:template: home_en`, `:save_as: en/index.html`, `:url: en/`, plus `seo_title` and
   `description`; create `content/pages/en/articles.rst` (`:slug: articles`).
5. **Settings**: `HOME_PAGES = {"fr": "/", "en": "/en/"}`. Consider
   `TRANSLATION_FEED_ATOM = "feeds/all-{lang}.atom.xml"` in `publishconf.py`.
6. **Newsletter**: decide whether English readers get a separate EmailOctopus list; if so,
   make `NEWSLETTER_FORM_ID` a per-language dict and update `partials/newsletter.html`.
7. **404 page**: it is French only (default language); add English text if needed.
8. **Articles**: translate the best articles with the same `:slug:` and `:lang: en`
   (they get `/en/<slug>` and hreflang automatically). Do not machine-translate without
   review.
9. Update the French FAQ entry "Existe-t-il une version anglaise ?" with the link.
10. `make publish && make check`, then update this document and `decisions.md`.
