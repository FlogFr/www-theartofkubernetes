## 2026-11-07 — SEO overhaul and redesign

- **Kindle only.** The book is sold only as a Kindle ebook on Amazon.fr (author's answer).
  The old "version PDF" wording of the offer was wrong and was removed.
- **No affiliate tag** for now (author's answer). Supported via `AMAZON_ASSOCIATE_TAG`.
- **English edition: structure only.** i18n plumbing is ready (`BOOKS`, `HOME_PAGES`,
  UI strings, hreflang), no English page is published (author's answer).
- **Moderate redesign** (author's answer): same identity (mountains, teal, logo, book
  visuals), conversion-oriented landing page, amber buy button.
- **Upcover template removed.** The pre-compiled template CSS, icon fonts, sliders and
  demo images (15.7 MB of theme files, ~975 KB loaded on every page, and demo HTML
  pages that were being published) were replaced
  by a custom theme (`themes/theartofkubernetes`) built with Tailwind CSS v4.
- **Compiled CSS is committed** so that Pelican builds (and deployments) need no Node.
- **URLs kept**: article slugs and the `/fr/<slug>` scheme are unchanged;
  `/fr/bienvenue` kept for the newsletter flow. Canonical form is extensionless.
- **Thin pages removed**: tag, category, author, archive pages and the empty
  `/fr/kubernetes-autoscaler` placeholder are no longer generated.
- **Sitemap as a template** instead of the `pelican-sitemap` plugin, so sitemap URLs match
  canonical URLs and exclude `noindex` pages.
- **Home page is a Pelican page** (`content/pages/fr/home.rst` saved as `index.html`) so
  future language versions are linked with hreflang automatically.
- **Images**: originals are never modified; optimized derivatives are generated by
  `scripts/make_images.py`. Only template demo images and byte-identical duplicates
  (theme copies of `BackgroundBook.jpg/.webp` and `logo-kubeedge.png`, still present in
  `content/images/`) were deleted.
- **Docs location**: rules in `claude/rules/` (imported by `CLAUDE.md` with `@`), docs in
  `claude/docs/`, as requested by the author.
- **French typography** handled by a filter (no-break spaces) rather than by hand.
- **PDFs not indexed**: `/assets/` is disallowed in `robots.txt`.
